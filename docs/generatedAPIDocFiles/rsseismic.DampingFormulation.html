rsseismic.DampingFormulation module#

class rsseismic.DampingFormulation.DampingFormulation(client: Client, modelId: str)#

Bases: _ProxyObject

Viscous damping options and preview plots for time-domain projects.

Use model.DampingFormulation (Damping Formulation tab in RSSeismic). Rayleigh damping and linear response previews are not available for nonlinear finite element analysis.

Preview tables are for checking your setup; they do not replace Run Compute.

getSettings() → DampingSettings#

Read damping options from the open project.

setSettings(settings: DampingSettings) → None#

Write damping options to the project.

Use getSettings(), edit the result, then pass it here.

setFrequencyIndependent(*, updateMatrix: bool = False) → DampingSettings#

Use frequency-independent viscous damping.

Rayleigh values and other options already on the project are unchanged.

setRayleigh(*, useFrequencies: bool = True, modeFrequencyOption: DampingModeFrequencyOption = DampingModeFrequencyOption.TWO, modeFreq1: float | None = None, modeFreq2: float | None = None, modeFreq3: float | None = None, modeFreq4: float | None = None, updateMatrix: bool = False, showFreqDomainSolution: bool | None = None, showTimeDomainSolution: bool | None = None) → DampingSettings#

Use Rayleigh damping defined by frequencies (Hz) or structural modes.

Any mode or frequency you omit is kept from the current project settings.

applyRecommendedFrequencies(profileName: str = '') → DampingSettings#

Apply the recommended Rayleigh frequency pair from the profile natural frequency.

Empty profileName uses the active profile.

getDampingCurveDataFrame(profileName: str = '') → pandas.DataFrame#

Normalized damping vs frequency for Rayleigh damping (same as the damping curve plot).

Points below 0.1 Hz are omitted. Column units are in dataframe.attrs["column_units"] when available.

getFrequencyDomainSolutionDataFrames(motionName: str, profileName: str = '') → tuple[pandas.DataFrame, pandas.DataFrame]#

Preview frequency-domain linear response: transfer function and spectral acceleration.

motionName is the motion in the project (file name without extension). Empty profileName uses the active profile. Does not update analysis results.

Returns a (transferFunction, spectralAcceleration) pair of DataFrames.

getTimeDomainSolutionDataFrames(motionName: str, profileName: str = '') → tuple[pandas.DataFrame, pandas.DataFrame]#

Preview time-domain linear response: transfer function and spectral acceleration.

motionName is the motion in the project (file name without extension). Empty profileName uses the active profile. Does not update analysis results.

Returns a (transferFunction, spectralAcceleration) pair of DataFrames.
