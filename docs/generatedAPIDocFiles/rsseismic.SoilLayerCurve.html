rsseismic.SoilLayerCurve module#

class rsseismic.SoilLayerCurve.SoilLayerCurve(client: Client, modelId: str, layerId: str)#

Bases: _ProxyObject

Fitted dynamics and discrete-point curve data for a profile soil layer.

Access via layer.Curve on a SoilLayer from model.Profiles.getSoilLayer(layerId). This is separate from layer.ReferenceCurve, which holds the reference curve used as input for curve fitting.

Use getDynamics / setDynamics for the fitted layer curve, or getDiscretePoints / setDiscretePoints when the layer uses a discrete-points soil model. Call runCurveFit to fit dynamics from the layer’s reference curve.
